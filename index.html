Patient Management System

A hospital backend split into five independent Spring Boot services — patients, appointments, auth, notifications and billing — that talk over REST, gRPC and Kafka. Booking an appointment validates the patient through patient-service, a billing account is opened automatically from a Kafka event, and a notification service stores every domain event it receives. The whole stack — services, Postgres and the message broker — comes up together with Docker Compose.

Controller → service → repository → mapper across every service, Springdoc/OpenAPI docs and ready-made .http request files.
